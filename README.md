# GildForm AI UI Tester

A lightweight frontend prototype for testing the new Gildform AI mesh generation and editing experience.

The application is built using **HTML, CSS, and vanilla JavaScript** and is intended primarily for UI and workflow testing before the AI functionality is integrated into the main GildForm application.

## Live Demo

https://magnificent-medovik-e51d1b.netlify.app/

> This is a test/staging deployment and is not the final production application.

## Purpose

This prototype is used to:

* Test the new AI workflow and user experience
* Validate the UI interactions
* Demonstrate the AI mesh generation/editing flow
* Gather feedback before integration into the main GildForm platform

## Technology

* HTML
* CSS
* Vanilla JavaScript
* Netlify

No frontend framework is currently used.

## Current Status

**UI prototype / tester**

The current version focuses on the frontend experience. The AI service and GildForm backend integration will be connected as part of the next stage of development.

## Future Integration

The final feature is planned to follow:


GildForm UI
     ↓
GildForm ERP API
     ↓
AI Service
     ↓
AWS S3 / Mesh Storage


The prototype is intentionally kept lightweight so the UI and workflow can be tested independently before being integrated into the production application.

## Deployment

The current tester is deployed on Netlify for easy access during development and review.
