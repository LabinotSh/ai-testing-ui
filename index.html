Mesh Generation

These are the actual AI mesh-generation endpoints. Both operations are asynchronous and use the same 202 → job polling flow as the other AI operations.
POST /mesh/generate POST
Generate a 3D STL mesh from a product/jewelry image. Select the source image and provide an optional prompt.
POST /mesh/sketch POST
Generate a 3D STL mesh from a jewelry sketch. Upload the sketch and optionally describe the intended design.
